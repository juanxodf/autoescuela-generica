# Autoescuela Genérica

Web app para autoescuelas: web pública, reserva de prácticas, contacto con la autoescuela y avisos por teléfono. Pensada para configurarse por autoescuela (logo, colores, profesores, coches) sin tocar código.

Proyecto de fin de ciclo (DAM).

## Stack

- **Front:** React + TypeScript + Vite, animaciones con anime.js, Tailwind
- **Back:** Supabase (PostgreSQL, Auth, RLS, Realtime)

## Estado

En desarrollo. La base de datos (esquema, funciones, reglas de reserva y RLS) ya está implementada en Supabase.
